# SQL Табличка

Тренажёр SQL: запросы выполняются в настоящей SQLite прямо в браузере (sql.js),
а результат показывается как лист Excel — буквы столбцов, номера строк, строка формул,
сумма/среднее по выделению, подсветка добавленных и изменённых строк.

## Запуск

```bash
source venv/bin/activate
uvicorn main:app --reload
```

Открой http://127.0.0.1:8000/

Можно и без сервера — просто открыть `static/index.html` в браузере.

## Структура

- `main.py` — FastAPI, отдаёт страницу на `/`
- `static/index.html` — весь тренажёр (HTML + CSS + JS)
- Учебная база (customers, products, orders) и уроки — в начале `<script>` в `index.html`
